### Project Overview
OriginGuard-X is a proposed explainable BGP anomaly-monitoring system designed to detect suspicious origin changes and subprefix announcements using BGP routing data, RPKI ROA information, and operator prefix inventory.

The system aims to generate evidence-based alerts that help analysts understand why a routing announcement is considered suspicious, while accounting for legitimate routing changes.

### Proposed Features
- BGP announcement ingestion and analysis
- RPKI origin validation
- Origin-change and subprefix anomaly detection
- Explainable security alerts
- Handling of legitimate multi-origin scenarios
- Evaluation using precision, recall, false positives, and alert latency
